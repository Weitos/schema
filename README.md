# Использование XML Schema

Решение учебного задания по созданию и валидации структуры XML-документа с помощью XML Schema (XSD).

## Структура репозитория
* `schema.xsd` — схема XML, описывающая правила, типы данных, ограничения и связи элементов.
* `sample.xml` — пример заполненного XML-документа, успешно проходящего проверку.
* `README.md` — описание проекта.

## Реализованные ограничения и правила
1. **Корневой элемент:** `<notebook>`.
2. **Офисы:** Элемент `<offices>` должен содержать как минимум один дочерний `<office>`. Каждый офис имеет уникальный текстовый атрибут `code`.
3. **Персонал:** Элемент `<person>` содержит уникальный атрибут `id` и ссылку на офис `office`. Значение `office` строго контролируется и должно существовать среди кодов созданных офисов (`xs:keyref`).
4. **Адрес:** Блок `<address>` содержит элементы `city`, `street` и `index`. Благодаря использованию тега `<xs:all>` они могут быть записаны **в любом порядке**. Почтовый индекс жестко ограничен регулярным выражением из 6 цифр (`\d{6}`).
5. **Телефоны:** Список телефонов `<phones>` может содержать любое количество тегов `<phone>` (включая ноль). Номер телефона валидируется по маске `\d{3}-\d{2}-\d{2}`. Необязательный атрибут `type` принимает значения только `work` или `home`.
